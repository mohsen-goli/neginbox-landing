# NeginBox — Responsive Business Landing Page

A responsive RTL business landing page built for **NeginBox**, a local under-bed storage (تخت‌باکس) business.

The project focuses on presenting products clearly, providing a smooth browsing experience, and making it easy for customers to contact the business directly.

## 🚀 Live Demo

https://neginbox.vercel.app/

## ✨ Features

* 📱 Fully responsive design for desktop, tablet and mobile
* 🇮🇷 RTL Persian interface
* 🔎 Product search
* 🗂️ Product category filtering
* 🛍️ Interactive product cards
* 🪟 Product detail modal
* 📱 Responsive mobile navigation
* 📞 Direct phone contact
* 💬 WhatsApp contact integration
* 📊 Google Analytics 4 integration

## 🛠️ Technologies

* HTML5

This project was developed as a real-world website for a local business.

* Explore available products
* Search and filter products
* View product details
* Contact the business directly
